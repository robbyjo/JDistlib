# Contributing

Run `./gradlew test` before submitting a change. New numerical ports should cite
the exact R 4.6.1 `src/nmath` file, include regression vectors generated by that
release, and test ordinary values plus log-tail and boundary behavior.

Keep cached sampling state explicit and per stream. A change must not add shared
mutable static work arrays or parameter caches. JDistlib-only distributions are
part of the supported surface and should remain covered when shared helpers are
changed.

Update [UPSTREAM.md](UPSTREAM.md) only after the relevant group has been fully
audited and tested.
