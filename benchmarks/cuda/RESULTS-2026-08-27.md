# JCuda likelihood smoke — 2026-08-27

Command:

```text
gradlew :jdistlib-cuda:cudaSmokeBenchmark
```

Environment: NVIDIA GeForce RTX 2080 (sm_75), CUDA runtime 12.9, driver 13.3,
Windows x86-64. The Java task used JCuda 12.6.0 and NVRTC; MSVC and `nvcc` were
not involved. Each timing is the median of five trials after five untimed warmup
evaluations. Each trial averages 20 evaluations for one/four states and eight
evaluations for 16/64 states.

and gradient throughput, not posterior ESS/second. The resident case keeps design
and outcome arrays on device; state inputs and result outputs still cross PCIe.
