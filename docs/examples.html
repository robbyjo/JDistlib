Run locally

Compile and validate the whole catalog

./gradlew check
./gradlew validateModelScripts

# Windows
gradlew.bat check
gradlew.bat validateModelScripts

check compiles every Java example against the packaged library and invokes the model-script validator. The validator requires at least thirty scripts, compiles all forty with representative data, checks their gradients, verifies finite initial densities, and executes generated quantities.
