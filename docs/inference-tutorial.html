Fit a posterior, then prove the fit is usable

Build a beta-binomial model, run four reproducible NUTS chains, inspect modern diagnostics, and export plots without a desktop UI.

Available in JDistlib 0.8.0
On this page1 Model2 Ingest data3 Sample4 Diagnose5 Graph6 Interpret

Step 1

Name data, constraints, and factors

A coin was tossed ten times and produced seven successes. A beta(2,2) prior is weakly centered at one half; the binomial likelihood supplies the evidence. JDistlib samples an unconstrained coordinate while exposing theta on (0,1), including the transform Jacobian automatically.

BayesianModel model = new ModelBuilder()
    .data("trials", 10)
    .data("successes", 7)
    .parameter("theta", Constraints.bounded(0, 1), 0.5)
    .factor("prior", new String[] {"theta"},
        ModelFactors.betaPrior("theta", 2, 2))
    .factor("observations",
        new String[] {"successes", "trials", "theta"},
        ModelFactors.binomialObservation(
            "successes", "trials", "theta"))
    .build();

GradientCheckResult check = Gradients.check(
    model, model.initialState(), 1e-5, 1e-5);
if (!check.passed()) throw new IllegalStateException(check.message());
Sampler coordinates: initial states and raw chain columns are unconstrained. Convert a draw with model.state(draw).scalar("theta").

Step 2 · file-backed data

Convert application data to primitive arrays

JDistlib does not prescribe CSV, JSON, database, or dataframe dependencies. Read the source with your application's preferred library, validate missing values, and bind the resulting array:

double[] y = McmcDataIngestionExamples.readNumericColumn(
    Paths.get("examples/data/normal-observations.csv"), "y");

BayesianModel dataModel = new ModelBuilder()
    .data("y", y)
    .parameter("mu", Constraints.real(), 0.0)
    .factor("prior", new String[] {"mu"},
        ModelFactors.normalPrior("mu", 0, 10))
    .factor("likelihood", new String[] {"y", "mu"},
        ModelFactors.normalObservations("y", "mu", 1))
    .build();

The complete data and model-script tutorial feeds this same CSV into both ModelBuilder and a compiled .jdm file.

Step 3

Run independently initialized chains

SamplingOptions options = SamplingOptions.builder()
    .warmupIterations(500)
    .sampleIterations(1000)
    .targetAcceptance(0.85)
    .maximumTreeDepth(10)
    .build();

double[][] initial = {{-1.0}, {-0.25}, {0.25}, {1.0}};
ChainResult[] chains = Chains.parallel(
    new NoUTurnSampler(), model, initial,
    options, 20260826L, 4);

The base seed deterministically creates independent streams. Results do not depend on worker scheduling. Warmup adapts step size and the mass matrix; retained draws start after adaptation.

Step 4

Read diagnostics as a group

McmcDiagnosticReport report = McmcDiagnostics.analyze(
    new String[] {"theta_free"}, chains);

ParameterDiagnostics theta = report.parameter("theta_free");
System.out.println(theta.rHat());
System.out.println(theta.bulkEffectiveSampleSize());
System.out.println(theta.tailEffectiveSampleSize());
System.out.println(report.sampler().divergences());

Minimum healthy screen

R-hat below 1.01, bulk and tail ESS above 100, zero divergences, no tree-depth saturation, and E-BFMI above 0.3.

Not a proof

Also check that posterior implications are scientifically plausible and that chains explore every relevant mode.

Step 5

Export reviewable graphs and a report

ChartSpec trace = DiagnosticGraphs.trace("theta_free", 0, chains);
ChartSpec ranks = DiagnosticGraphs.ranks("theta_free", 0, 20, chains);
ChartSpec acf = DiagnosticGraphs.autocorrelation(
    "theta_free", 0, 40, chains);
ChartSpec energy = DiagnosticGraphs.energy(30, chains);

String svg = trace.toSvg(900, 360);
String csv = ChainExport.toCsv(new String[] {"theta_free"}, chains);
String html = InferenceHtmlReport.render(
    "Coin posterior", report, model.graph(),
    trace, ranks, acf, energy);

ChartSpec is renderer-neutral: JSON and CSV feed another plotting library, SVG is directly publishable, and the HTML report is self-contained.

Step 6

Summarize on the scientific scale

double mean = 0.0;
for (int draw = 0; draw < chains[0].size(); draw++) {
  mean += model.state(chains[0].sample(draw)).scalar("theta");
}
mean /= chains[0].size();

For this conjugate example, the exact posterior is beta(9,5), with mean 9/14. That analytic answer is a valuable end-to-end check of transforms, sampling, and interpretation.
