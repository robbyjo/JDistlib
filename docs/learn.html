Inference reference · 0.8.0+

Go deeper after the first posterior

The complete inference guide covers sampler selection, warmup, R-hat, ESS, MCSE, divergences, E-BFMI, graphing, performance, checkpoints, and failure handling. Continue with the data and model-script tutorial, the Stan-user migration guide, or browse the complete executable example center.

After hypothesis tests · 0.7.0+

Control errors across many p-values

The multiple-testing guide covers Bonferroni, Holm, Hochberg, Hommel, Šidák, BH, BY, adaptive BKY and GBS, weighted FWER/FDR, grouped and online procedures, discrete DBH, log-scale and censored inputs, and Storey q-values through one compact static API.
