Stan-inspired scripts · language 0.8

Write a model as text, run it as Java

Compile a vectorized normal location/scale model, validate its gradient, sample it with NUTS, and generate posterior predictions.

Inspired by Stan; not Stan-compatible

Example

A second complete script

data {
  int<lower=1> N;
  vector[N] y;
}
parameters {
  real mu;
  real<lower=0> sigma;
}
model {
  mu ~ normal(0, 10);
  sigma ~ exponential(1);
  y ~ normal(mu, sigma);
}
generated quantities {
  real y_rep = normal_rng(mu, sigma);
}

The vector sampling statement expands over every observation. Positive sigma is transformed to unconstrained space and its Jacobian is included automatically.

Compile

Data maps directly to Java arrays

Map<String, double[]> data = new LinkedHashMap<>();
data.put("N", new double[] {5});
data.put("y", new double[] {-.2, .1, .4, 0, .3});

CompiledModelScript script = ModelScript.compile(source, data);
BayesianModel model = script.model();
GradientCheckResult check = Gradients.check(
    model, model.initialState(), 1e-5, 1e-5);

The compiler reports line and column diagnostics, validates data types, lengths and bounds, and constructs the same intermediate model as the Java builder. Input data is defensively copied.

Sample and generate

Use every inference tool unchanged

ChainResult chain = new NoUTurnSampler().sample(
    model, model.initialState(), options,
    new MersenneTwister(2026));

Map<String, double[]> prediction = script.generate(
    chain.sample(0), new MersenneTwister(2027));

Diagnostics, graphing, exports, checkpoints, and parallel chains operate on the compiled model without language-specific adapters.

Another pattern

Gamma–Poisson count-rate model

data { int y; }
parameters { real<lower=0> lambda; }
model {
  lambda ~ gamma(2, 1);
  y ~ poisson(lambda);
}
generated quantities {
  int y_rep = poisson_rng(lambda);
}

Script gamma uses shape/rate, matching Stan. JDistlib converts to the scale convention used by its underlying random generator. Both examples are compiled by every check build in examples/ModelScriptExamples.java.

Deployment

Generate or cache an isolated Java wrapper

ModelScriptCli model.jdm com.example.GeneratedModel \
  build/generated/GeneratedModel.java

ModelSourceGenerator emits a wrapper implementing GeneratedModelFactory. ModelCompilationCache hashes exact source with SHA-256, compiles under a caller-selected cache root, and returns a closeable isolated class loader.

Scope: language 0.8 intentionally omits loops, functions, ODEs, matrices, and Stan’s full distribution library. Consult the supported-surface reference; never assume arbitrary Stan source is accepted.

Move between text and Java by model complexity

Use scripts for concise supported models and generated quantities. Use ModelBuilder or a direct DifferentiableLogDensity for custom likelihoods, complex gradients, or mixed algorithms. Both routes preserve the same sampler and diagnostic contracts.
