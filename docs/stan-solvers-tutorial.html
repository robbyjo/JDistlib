Root finding

Solve F(x) = 0 with damped Newton steps

AlgebraicSolver.Result root = AlgebraicSolver.solve(
    (x, parameters, data, residual) ->
        residual[0] = x[0] * x[0] - parameters[0],
    new double[] {1}, new double[] {2}, null,
    AlgebraicSolver.Options.defaults());
double sqrtTwo = root.solution()[0];

The dense solver estimates a Jacobian by scaled finite differences, uses pivoted elimination, and damps a Newton step until the residual decreases. Inspect iterations(), evaluations(), and residualNorm(); non-convergence, singular Jacobians, and non-finite residuals are explicit failures.

Non-stiff dynamics

Integrate at requested observation times

double[][] states = OdeSolver.integrate(
    (time, y, parameters, data, derivative) ->
        derivative[0] = -parameters[0] * y[0],
    new double[] {1}, 0,
    new double[] {.25, .5, 1},
    new double[] {.8}, null,
    OdeSolver.Options.defaults());

The adaptive Dormand–Prince 5(4) integrator controls a scaled local error and lands exactly on each increasing output time. Configure relative/absolute tolerances, initial step, and maximum steps with OdeSolver.Options.

Residual dynamics

Express an index-1 DAE as F(t,y,y') = 0

double[][] states = DaeSolver.integrate(
    (time, y, derivative, parameters, data, residual) ->
        residual[0] = derivative[0] + parameters[0] * y[0],
    new double[] {1}, 0, times,
    new double[] {.8}, null,
    AlgebraicSolver.Options.defaults());

The DAE solver takes an implicit-Euler step at every requested time and solves that step's nonlinear residual with the algebraic solver. Closely spaced output times increase accuracy for smooth systems.

Model integration

Precompute data-only trajectories or write a Java factor

If the system depends only on observed data, solve it first and bind the flattened trajectory through the script data map. If it depends on sampled parameters, call the solver from a Java-authored ModelFactor; gradient-based sampling then requires a matching differentiable factor or a sampler that does not require gradients. Direct Stan higher-order solver syntax and sensitivity autodiff are not yet accepted by compileStan.

Algorithmic boundary

Choose the solver that matches the problem

The v0.8.3 ODE method targets non-stiff systems; the DAE method targets modest index-1 systems. Stiff BDF/Rosenbrock integration, higher-index DAE reduction, event handling, and forward/adjoint sensitivities remain roadmap items. Run the complete companion at StanSolverExamples.java, and verify the solver tests with ./gradlew test --tests jdistlib.StanSolverTest.
